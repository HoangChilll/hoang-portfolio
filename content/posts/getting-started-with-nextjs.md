# Getting Started with Next.js 16

Next.js 16 brings several improvements to the App Router, including improved caching APIs, better TypeScript support, and new file conventions.

## What's new

- Stable `use cache` directive for granular cache control
- Improved `params` as Promises in dynamic routes
- Better error overlays and debugging experience

## Getting started

```bash
npx create-next-app@latest my-app
```
