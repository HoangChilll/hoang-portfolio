# Design Skill

## Core Purpose
Unified design system for:
- UI/UX design (shadcn + Tailwind)
- Brand identity
- Layout + visual hierarchy
- Components consistency
- Simple marketing assets

---

## When to Use
- Building UI pages
- Designing portfolio / SaaS / dashboard
- Creating consistent design system
- Choosing colors, typography, spacing
- Improving visual hierarchy

---

## UI Design Rules
- Mobile-first design
- Use shadcn/ui components when possible
- Use Tailwind for all styling
- Keep UI minimal, modern, SaaS-like
- One primary CTA per page
- Clear visual hierarchy

---

## Brand Rules
- Consistent color system (no random hex)
- Limit to 1 primary + 1 accent color
- Typography max 2 fonts
- Maintain tone consistency across UI

---

## Layout Rules
- Use grid-based layouts
- Use spacing system (4/8px scale)
- Avoid clutter and over-design
- Prefer whitespace over decoration

---

## Component Rules
- Reuse components instead of recreating
- Prefer composition over duplication
- Keep components single-responsibility

---

## Output Types
- UI screens
- landing pages
- dashboards
- simple banners
- basic brand visuals

---

## Anti-patterns
- No neon / chaotic colors
- No inconsistent spacing
- No over-animated UI
- No unnecessary complexity
- No mixing too many design styles

---

## Integration
Works with:
- ui-styling skill (React + shadcn)
- design-system skill (tokens)
- brand skill (identity rules)
