# UI Styling Skill (shadcn + Tailwind)

## Core Stack
- Use shadcn/ui components (Radix UI based)
- Use Tailwind CSS utility-first styling
- Mobile-first responsive design
- TypeScript-first React components

---

## UI Rules
- Build with reusable components only
- Prefer composition over custom styling
- Keep UI minimal, modern, SaaS-style
- Every page must have clear hierarchy
- One primary CTA per screen

---

## Styling Principles
- Use Tailwind for all styling (no inline CSS)
- Use design tokens (spacing, colors, typography)
- Avoid random colors or hardcoded styles
- Use consistent spacing scale (4px / 8px system)

---

## Component Rules
- Use shadcn/ui: Button, Card, Dialog, Form, Table
- Do not reinvent existing UI components
- Extend components instead of rewriting

---

## Responsive Rules
- Mobile-first design
- Must support: 375px, 768px, 1024px+
- Use Tailwind breakpoints only

---

## Dark Mode
- Must support dark mode consistently
- Use semantic color tokens (not raw hex)

---

## Anti-patterns
- No inline styles
- No inconsistent spacing
- No over-animated UI
- No unnecessary complexity
